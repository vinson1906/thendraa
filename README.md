
# THENRAA — Coconut Value-Added Products

**One Coconut. Endless Possibilities.**

THENRAA is a modern, responsive business website for a coconut-based enterprise from Erode, Tamil Nadu, India. The website showcases available coconut products, the brand's story, future product plans, vision, sustainability direction, and contact information.

## 🌐 About the Project

The website presents THENRAA's mission of transforming coconuts into useful, value-added products. It provides visitors with an overview of the business, its current product range, and its plans to explore opportunities across food, beverages, personal care, agriculture, and materials.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices.
- Modern, nature-inspired user interface.
- Multi-page navigation using React Router.
- Home page introducing the THENRAA brand.
- Products page showcasing currently available products.
- About Us page presenting the company's story.
- Future Products page displaying planned product ideas.
- Vision and Sustainability page highlighting long-term goals.
- Contact page with business contact details and enquiry form UI.
- Reusable React components and organised project structure.
- SEO-friendly page metadata.
- Custom 404 page.
- Smooth transitions and interactive UI elements.

## 🥥 Products

### Currently Available Products

- **Coconut Oil** — A versatile coconut-based product and the beginning of THENRAA's product range.
- **Coconut Tree Saplings** — For planting coconut trees or expanding existing plantations.
- **Coconut Oil Cake** — Obtained after oil extraction from dried coconut kernels.

### Future Product Plans

THENRAA aims to explore additional coconut-based products across food, beverages, personal care, household applications, agriculture, and materials.

Future product ideas are presented for informational purposes and should not be considered currently available products.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js (a current supported LTS version)
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/thenraa-business-website.git
```

### 2. Navigate to the Project Directory

```bash
cd thenraa-business-website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview the Production Build

```bash
npm run preview
```

## 🚀 Deployment

This static website can be deployed using platforms such as:

- [Vercel](https://vercel.com/)
- [Netlify](https://www.netlify.com/)

### Deployment Steps

1. Push the project to GitHub.
2. Import the repository into your preferred hosting platform.
3. Configure the build command as `npm run build`.
4. Set the output directory to `dist`.
5. Deploy the website.
6. Configure a custom domain if required.

**Note:** If React Router is used with browser-based routing, configure your hosting platform to redirect application routes to `index.html` so direct page visits and refreshes work correctly.
